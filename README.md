# SEALProjet
SEAL est un projet dans lequel on essaye de ameliorer les déplacements de gens sportifs.

Comment limiter les contraintes liées au transport et au stockage temporaire d’affaires humides après une activité sportive lorsqu’elles ne peuvent pas être séchées immédiatement ?

Le besoin concerne l’humidité persistante, le risque de mouiller les autres affaires, l’absence de ventilation, le volume du matériel, le transport de plusieurs sacs, l’organisation après le sport, le stockage temporaire et l’entretien des équipements.
